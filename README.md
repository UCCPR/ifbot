# TOARU Gacha Bot - 某个魔魔人游戏的自动抽卡QQ机器人

基于 Napcat 框架的自动抽卡QQ机器人，支持盲盒系统、保底机制、碎片兑换等功能。

## 功能特性

### 抽卡系统
- **单抽** - 消耗300呱太抽取一张卡牌
- **十连** - 消耗3000呱太抽取十张卡牌
- **十抽跳过** - 十连直接出结果，跳过盲盒阶段
- **盲盒系统** - 抽卡后以盲盒形式展示，用户可选择开启
- **保底机制** - 150抽必出FES限定三星
- **十连保底** - 十连必出至少1个二星

### 盲盒机制
- 盲盒图片根据星级显示不同样式
- フェス限定三星使用特殊盲盒图（gacha_tmb_03_02_b.png）
- 黑色神秘盲盒（2%概率），开出后为2星或3星
- 突变机制：开盲盒时有概率发生星级突变
  - 不突变：80%
  - 1星→2星：15%
  - 1星→3星：5%
  - 2星→3星：20%

### 三星概率分配
- 期間限定：35%
- フェス限定：25%
- 其他三星：40%

### 碎片系统
- 1星卡自动转化为1个红色碎片
- 2星卡自动转化为1个蓝色碎片
- 红色碎片可兑换5呱太
- 蓝色碎片可兑换20呱太

### 签到系统
- 每日签到获得30000呱太

### 个人记录
- 显示累计抽卡、累计三星、碎片数量
- 分页显示所有三星卡收藏（每页10张）
- 重复三星卡显示计数标记
- 支持上一页/下一页翻页

### 排行榜
- 根据战力排名（前十名）
- 战力计算：フェス限定×10 + 期間限定×8 + 其他三星×7 + 二星×3

### FES统计
- 抽出FES角色时显示全服第几个该角色
- 触发FES保底时显示提示信息

### 特殊命令
- **三王女** - 输出十个相同的三星卡（ID: 207832001）

### 配队系统
- 使用三星卡配置队伍
- 队伍包含6个战斗位和6个支援位
- 支持分页查看拥有的三星卡
- 队伍展示图片背景为1920x1080

## 安装步骤

### 1. 环境要求
- Python 3.8+
- Napcat QQ机器人框架

### 2. 安装依赖
```bash
pip install flask pillow openpyxl
```

### 3. 配置Napcat
参考 [NAPCAT_SETUP.md](NAPCAT_SETUP.md) 配置Napcat框架

### 4. 配置机器人
修改 `.env` 文件或直接修改 `gacha_bot.py` 中的配置：
```python
NAPCAT_URL = "http://127.0.0.1:3000"  # Napcat API地址
NAPCAT_TOKEN = "your_token"           # Napcat Token
```

### 5. 准备资源文件
- `卡牌信息.xlsx` - 包含 BattleCard资源和 AssistCard资源 sheet
- `iconimage/` - 角色卡图目录（card_cutin_xxx.png）
- `level/` - 框和背景图目录（gacha_tmb_xx_yy.png）

### 6. 运行机器人
```bash
python gacha_bot.py
```

## 使用说明

### 基本命令
| 命令 | 说明 |
|------|------|
| 单抽 | 抽取一张卡牌（300呱太） |
| 十连 | 抽取十张卡牌（3000呱太） |
| 十抽跳过 | 十连直接出结果 |
| 获取呱太 | 获得10000呱太 |
| 签到 | 每日签到（30000呱太） |
| 个人记录 | 查看个人抽卡统计 |
| 兑换呱太 | 用碎片兑换呱太 |
| 排行榜 | 查看战力排行榜 |
| 详细信息 | 查看上次抽卡详细结果 |
| 帮助 | 显示帮助信息 |
| 三王女 | 输出十个相同三星卡 |

### 盲盒开箱命令
| 命令 | 说明 |
|------|------|
| 1/2/3... | 开启指定编号的盲盒 |
| 选择1/选择2... | 开启指定编号的盲盒 |
| 全部开 | 开启所有盲盒 |
| 剩下的全部开 | 开启剩余未开的盲盒 |

### 个人记录翻页
| 命令 | 说明 |
|------|------|
| 下一页 | 查看下一页三星卡 |
| 上一页 | 查看上一页三星卡 |

### 配队命令
| 命令 | 说明 |
|------|------|
| 队伍 | 查看当前队伍配置（图片） |
| 队伍 我的卡 | 查看拥有的三星卡（10张/页） |
| 队伍 我的卡 下一页 | 查看下一页三星卡 |
| 队伍 我的卡 上一页 | 查看上一页三星卡 |
| 队伍 设置 位置 序号 | 将当前页序号的卡牌加入队伍 |
| 队伍 清除 位置 | 清除该位置的卡牌 |
| 队伍 清空 | 清空所有队伍配置 |
