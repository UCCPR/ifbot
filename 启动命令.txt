============================================
  QQ机器人 (qq_bot_ws.py) 部署指南
  更新: 2026-06-19
============================================

一、首次部署
============================================

1. 上传文件到服务器 /home/root/zmdbot/

2. 安装依赖:
   pip3 install qq-botpy flask requests pillow openpyxl

3. 安装 cloudflared (图片隧道):
   curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -o /usr/local/bin/cloudflared
   chmod +x /usr/local/bin/cloudflared

4. 编辑 config.py 填写:
   QQ_BOT_APP_ID  = "你的AppID"
   QQ_BOT_SECRET  = "你的Secret"
   QQ_BOT_TOKEN   = "你的Token"
   ADMIN_QQ       = "你的openid"
   IMAGE_HOST     = ""  (启动后自动填写)


二、生产环境部署 (24/7 systemd 守护进程)
============================================

  cd /home/root/zmdbot
  sudo bash setup_services.sh

安装后Bot崩溃自动重启。图片服务由Bot内置启动（端口18080），无需单独服务。

管理命令:
  systemctl status qqbot              # 查看状态
  journalctl -u qqbot -f              # 实时日志
  systemctl restart qqbot             # 重启
  systemctl stop qqbot                # 停止

  # 隧道独立管理
  systemctl status qqbot-tunnel       # 隧道状态
  journalctl -u qqbot-tunnel -f       # 隧道日志

  一键状态检查:
  bash status.sh                      # 查看进程/PID锁/端口/隧道全貌

隧道地址变化时更新:
  journalctl -u qqbot-tunnel -n 5 | grep trycloudflare
  复制地址到 config.py 的 IMAGE_HOST
  systemctl restart qqbot


三、开发调试 (前台运行)
============================================

终端1 - Bot:
  cd /home/root/zmdbot
  python3 qq_bot_ws.py

终端2 - 图片隧道:
  cloudflared tunnel --url http://localhost:18080
  拿到地址后更新 config.py IMAGE_HOST，重启Bot

一键脚本:
  ./start_qq_bot.sh    # 启动
  ./stop_qq_bot.sh     # 停止

六、管理员命令 (仅 config.py 中 ADMIN_ID 可使用)
============================================

所有管理员命令必须在群聊中 @Bot 使用，格式为:
  @Bot <命令> @目标用户

1. 增减呱太
   @Bot 100呱太 @某人          → 增加 100 呱太
   @Bot 扣100呱太 @某人         → 扣除 100 呱太（余额不足则失败）
   @Bot 减100呱太 @某人         → 同上

2. 增减蓝碎片
   @Bot 50蓝碎片 @某人          → 增加 50 蓝碎片
   @Bot 扣50蓝碎片 @某人         → 扣除 50 蓝碎片

3. 增减红碎片
   @Bot 30红碎片 @某人          → 增加 30 红碎片
   @Bot 扣30红碎片 @某人         → 扣除 30 红碎片

4. 全榜替（排行榜迁移旧QQ号→新openid）
   @Bot 全榜替 <新openid> <旧QQ号>
   例: @Bot 全榜替 A1B2C3D4E5 123456789
   → 排行榜中所有 user_id=123456789 的条目改为 A1B2C3D4E5
